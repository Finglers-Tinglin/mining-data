# mining-data
This repository is designed to serve as my final project for data analysis.
The dataset I currently intend to use is related to mining production in India: https://www.kaggle.com/datasets/vineetkothari/coalproduction
However, I'm also fairly interested in the 3 other datasets I found, although they seem quite complex and difficult to navigate, which might actually be a good thing for this project.
World Factbook by CIA: https://www.kaggle.com/datasets/lucafrance/the-world-factbook-by-cia
Quality Prediction in a Mining Process: https://www.kaggle.com/datasets/edumagalhaes/quality-prediction-in-a-mining-process
Mining Core Detection Pytorch: https://www.kaggle.com/code/cristianminas/mining-core-detection-pytorch-baseline

A tertiary objective sprang to mind as I was researching this project once I saw how Cristian Matos used Pytorch to measure and determine RQD through Deep Learning, which I believe could help me at work to simplify and automate the procedures I go through every day.
